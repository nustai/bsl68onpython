# BSL.v68 (Python Edition)
Python Brawl Stars server emulator for version 68. 
Based on the original [C# BSL V68](https://github.com/LkPrtctrd/BSL.v68).

## 🚀 How to Play

### 🖥️ Server
1. Download and extract the repository.
2. Run the server using terminal:
   ```bash
   python main.py
   ```
3. Follow the client instructions below.

### 📱 Android Client
1. [Download the APK here](https://mega.nz/file/rNFSwa7A#TBNCCfyVG3xUkykvnQhM77qlu63wvzGpG5W1bGjR1As) (~1.11 GB).
2. Change `redirectHost` (also `redirectPort` and `offlineBattles` if needed) in the frida config inside the APK: `lib/arm64-v8a/libBSL.c.so`.
3. Install the modified APK and enjoy playing!
